Design 03-E — Reversible lanesEach lane is a GPU node: when the agents send more prefill traffic, Evolving Infra turns decode lanes around, like reversible lanes at rush hour.

Traffic shifts. Lanes switch.

Animation: two roads of nine lanes serve the same agents. Each lane is a GPU node; prefill lanes run right and decode lanes run left. The agents change from math agents to computer-use agents and send more prefill traffic. On the fixed split road, requests back up at the prefill entrance while several decode lanes stay empty. On the Evolving Infra road, three decode lanes turn around and become prefill lanes, so nothing backs up and every lane carries traffic.
