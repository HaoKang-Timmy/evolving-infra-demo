04 / KV cache management

Kang Hao: animate a tree, like Figure 4 of the report (“Counts follow agent context management and KV transfers”).

04-AFigure 4, in motion

The report’s Figure 4 as one tree that changes step by step: a consecutive request, compaction, a P2P transfer and a P2D transfer. Then P1 runs out of room and evicts the zero-count copies first, while LRU would evict branch 2’s KV.

Open ↗ 04-BIdle is not unused

One prefill node. An agent waits while its sub-agent works, compacts and finishes. A host-memory bar ordered by last use shows that LRU would drop the waiting agent’s KV, while the counts keep it.

Open ↗ 04-CMove the branch, free the copy

A cluster view next to the tree. The router sends branch 1 to the less busy prefill node, which fetches its KV while the request waits. The counts move with the branch, and P1 evicts the copy left behind, not the KV of the branch waiting for a tool.
