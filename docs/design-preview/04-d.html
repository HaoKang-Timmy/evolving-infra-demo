Animation. Three agents share a full GPU memory. Agent A waits for a tool, agent C is done, and agent B compacts its history, so the context of C and the old history of B are no longer needed. New context arrives. Existing systems with LRU eviction drop the context of A, because A was idle the longest, so A must recompute it when its tool returns. Evolving Infra drops the context that is done instead, so A resumes at once.
