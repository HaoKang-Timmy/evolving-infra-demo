05 / THE SYSTEM

Three ideas.
One serving system.

The planner changes where compute runs. The router and directory decide where context is reused. Symmetric engines and a shared KV pool let those decisions evolve independently.

Measurement and comparison

These are the report’s stationary benchmarks: a 30-minute warmup followed by a one-hour measurement window. Both systems start at 6P3D. Models use NVFP4 weights and FP8 KV cache.

Each model runs across nine nodes with four GB300 GPUs per node. Dynamo uses the SGLang Model Gateway with cache-aware prefill routing, round-robin decode routing, and HiCache with LRU eviction. Host KV capacity is matched.

The figures measure individual LLM requests. The opening video shows a particular coding run; its 4.2× headline and these report figures use different aggregations. The charts here retain the report’s values.

What these experiments establish

The fixed-split comparison measures the combined effect of the decoupled infrastructure and KV-reuse-aware routing and eviction. It does not isolate eviction alone. The report separately measures asynchronous fetching at 1.12× throughput with routing held constant.

Online adaptation is almost cost-free on this stationary workload. Its benefit when demand shifts is measured in the three-hour experiment above. These are different experiments, so their speedups should not be added or multiplied.
